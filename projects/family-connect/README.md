# Демо: бриф MegaFon «Связь для близких и собственных устройств»

Пример работы агента Product Factory Strategist на одной задаче: от брифа руководителя
цифрового продукта до утверждённой стратегии. Агент работал в Claude Code, руководитель
(PM) отвечал на всех гейтах. Дата: 2026-11-22. Только открытые данные.

## Что читать

| | Файл |
|---|---|
| **Итоговый документ (PDF, рус.)**: продуктовая и коммуникационная стратегия в пяти частях по структуре брифа, каждая цифра связана с приложением-реестром | [`export/deliverable.pdf`](export/deliverable.pdf) (то же в [`deliverable.md`](deliverable.md)) |
| Задача руководителя | исходный бриф: [`sources/megafon-brief.pdf`](sources/megafon-brief.pdf); постановка, подтверждённая PM: [`brief.md`](brief.md) |
| Исходные материалы агента | [`sources/`](sources/): бриф MegaFon; открытые источники с датами и ссылками в реестре [`evidence.md`](evidence.md) |
| Продуктовая стратегия | `deliverable.pdf`, части 1–4; рабочая версия: [`strategy.md`](strategy.md), раздел 1 |
| Коммуникационная стратегия | `deliverable.pdf`, часть 2 (предложение, путь к клиенту, каналы); [`strategy.md`](strategy.md), раздел 2: аудитория, барьеры, ключевое сообщение, каналы, таблица «обещание ↔ возможность» |
