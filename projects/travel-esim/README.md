# travel-esim — test project (not the case demo)

An end-to-end test of the agent run on 2026-11-17 on a self-chosen question
("Should a Russian operator launch a travel data eSIM?"), public data only.

`sources/finance-note-2026-11.md` contains **invented test figures**, added on
purpose to exercise the `reassess` workflow. Conclusions that use them
(E-031…E-040, D-001 review) are test output, not analysis of a real operator.

The case demonstration project is `projects/family-connect` (MegaFon's brief).
