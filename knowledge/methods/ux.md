# UX audit checklist

Per screen/step, judged against the user's goal from the brief:

1. **Clarity** — can the user tell what this is and what to do next within a few seconds?
2. **Hierarchy** — is the most important element the most prominent?
3. **Price and conditions** — total cost, period, auto-renewal and limits visible before commitment?
4. **Effort** — number of steps, fields, context switches; unnecessary data requests.
5. **Trust** — proof, guarantees, recognisable brand cues, no dark patterns (hidden opt-ins, confirm-shaming).
6. **Feedback and errors** — what happens on wrong input or failure (often not visible: say so).
7. **Consistency** — same terms and promises as the communication strategy.
8. **Accessibility** — contrast, text size, tap targets (as far as visible).

Severity: **blocks** (user cannot reach the goal), **slows** (friction, likely
drop-off), **cosmetic**. Every observation cites file and region.
